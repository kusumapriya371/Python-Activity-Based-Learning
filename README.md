## Project Overview
This repository contains ten Python case studies developed for the first-year B.Tech Python Programming Activity-Based Learning assignment. Each case study includes a problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, source code, test cases, sample output screenshot, and conclusion.

## Repository Structure
- `Case_Study_*/program.py` — Python source code.
- `Case_Study_*/documentation.md` — case study documentation.
- `Case_Study_*/sample_output.txt` — captured output from the sample program.
- `Case_Study_*/output_screenshots/sample_output.png` — terminal-style sample output image.
- `Consolidated_Report.pdf` — combined report for all ten case studies.
- `case_studies.json` — structured case study data for reference.

## How to Run
Use Python 3.10 or later. Open a terminal in a case study folder and run:

```bash
python program.py
```

The programs use illustrative sample data and academic assumptions. Update assumptions and sample inputs if your faculty provides different rules. Review each program and practise explaining the logic before demonstration.

## Academic Integrity / Demonstration Note
These are editable learning examples. Please read and test every program yourself, ensure the rules match the assignment instructions, and be ready to explain the algorithm, conditions, loops, and output.
