# Publish this folder to GitHub

1. Sign in at https://github.com.
2. Click **New repository**.
3. Repository name: `Python-Activity-Based-Learning`.
4. Choose Public or Private according to your faculty's instructions. Do not initialize with another README because this folder already has one.
5. Create the repository.
6. On your computer, open a terminal in this project folder and run:

```bash
git init
git add .
git commit -m "Add Python ABL case studies and report"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Python-Activity-Based-Learning.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your actual GitHub username. The repository is not created online until you complete these steps or upload the files through GitHub's website.
